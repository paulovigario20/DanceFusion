# Dance Fusion - Academia de Dança

🎭 Micro landing page profissional e responsivo para a escola de dança **Dance Fusion**, no Montijo.

## 📋 Descrição

Um site moderno, premium e totalmente responsivo com design energético que reflete a personalidade artística e jovem da Academia de Dança. A página foi desenvolvida com HTML, CSS e JavaScript puro, seguindo as melhores práticas de UX/UI e SEO.

## ✨ Características

- ✅ Design premium, energético e moderno
- ✅ Fundo escuro com detalhes em roxo, rosa, branco e gradientes
- ✅ Totalmente responsivo (Mobile-first)
- ✅ Animações suaves e interativas
- ✅ SEO otimizado com meta tags e Open Graph
- ✅ Navigationbar sticky com menu mobile
- ✅ Chamadas à ação fortes e claras
- ✅ Múltiplas secções: Hero, Porquê Escolher, Aulas, Destaques, Contacto
- ✅ Integração com redes sociais (Facebook, Instagram)
- ✅ Botões de contacto direto (telefone, WhatsApp, Google Maps)
- ✅ Código limpo e bem organizado

## 🚀 Como Usar

### Localmente

1. Clone o repositório:
```bash
git clone https://github.com/paulovigario20/DanceFusion.git
cd DanceFusion
```

2. Abra o ficheiro `index.html` num navegador web:
```bash
# Opção 1: Duplo clique no ficheiro
# Opção 2: Use um servidor local
python3 -m http.server 8000
# Ou com Node.js
npx http-server
```

3. O site será aberto em `http://localhost:8000`

### Deploy

#### **Netlify**
1. Acesse [netlify.com](https://netlify.com)
2. Faça login com GitHub
3. Clique em "New site from Git"
4. Selecione o repositório `DanceFusion`
5. Deploy automático em cada push para `main`

#### **Vercel**
1. Acesse [vercel.com](https://vercel.com)
2. Clique em "New Project"
3. Importe o repositório GitHub
4. Deploy automático configurado

#### **Railway**
1. Acesse [railway.app](https://railway.app)
2. Clique em "New Project"
3. Deploy from GitHub
4. Selecione o repositório
5. Configure as variáveis de ambiente se necessário

## 🔧 Customização

### Adicionar Imagens
Substitua os URLs dos placeholders:
```html
<!-- No lugar de: https://via.placeholder.com/600x600?text=Dance+Fusion+Hero -->
<!-- Use a sua imagem: -->
<img src="images/seu-hero.jpg" alt="Dance Fusion">
```

### Alterar Cores
Modifique as variáveis CSS em `styles.css`:
```css
:root {
    --accent-purple: #9d4edd;  /* Mude para a sua cor */
    --accent-pink: #ff006e;    /* Mude para a sua cor */
}
```

### Adicionar Nova Secção
1. Adicione o HTML em `index.html`
2. Crie os estilos em `styles.css`
3. Adicione interatividade em `script.js` se necessário
4. Atualize o menu de navegação
